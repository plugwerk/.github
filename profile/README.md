# Plugwerk

**Plugwerk is a self-hosted plugin marketplace for JVM applications, built
on [PF4J](https://github.com/pf4j/pf4j).** It lets product teams ship
extensible software — third-party integrations, custom workflows,
white-label features — without rebuilding plugin infrastructure from
scratch.

## Repositories

- **[plugwerk/plugwerk](https://github.com/plugwerk/plugwerk)** — server
  (Spring Boot 4 + Kotlin, React/MUI admin UI) and client core
  (PF4J integration plugin, Kotlin/JVM).
- **[plugwerk/examples](https://github.com/plugwerk/examples)** —
  sample plugins demonstrating the SPI surface.
- **[plugwerk/website](https://github.com/plugwerk/website)** —
  marketing site and public documentation.

## Get Started

Read the [Quickstart](https://github.com/plugwerk/plugwerk#quickstart)
in the main repository, then run the local stack with Docker Compose.
